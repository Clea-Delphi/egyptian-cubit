# The Egyptian Cubit Ruler

**The royal cubit (meh niswt) divided into 28 fingers.**

The Egyptian Cubit Ruler is a proportional instrument for exploring the royal
cubit as the ancient builders and scribes used it — with the phi mark, the
equatorial foot, and the harmonic cascade within each finger.

## What it does

- **The 28-Mark Ruler** — click any mark to see its meaning. Key marks:
  16 = Egyptian foot, 20 = remen, 24 = phi, 28 = royal cubit.
- **The Harmonic Cascade** — each finger (0.7406 in) divides into 15 nested
  units, each n/(n+1): 1/2, 2/3, 3/4 … 15/16, converging toward the whole
  finger.
- **The Eye of Horus Fractions** — 1/2 + 1/4 + 1/8 + 1/16 + 1/32 + 1/64 =
  63/64, with the missing 1/64 as the "Thoth magic." An honest note explains
  the modern scholarship (Jim Ritter) that these fractions began as hekat
  capacity submultiples in hieratic grain records.
- **The 1/7 Hieroglyph Column** — the column hieroglyphs were made on, 1/7 the
  width of a cubit (4 fingers).
- **The Old Kingdom Canon — the 6×6 Division of the Cubit** — the drawing
  canon set the standing figure at 18 squares from soles to hairline; the
  canonical figure height is 3 royal cubits, so each grid square is exactly
  1/6 of a royal cubit. A 6×6 grid of the cubit makes 36 cells.
- **Cross-References** — the Ssp (solar) and Mtt Srj (lunar) cubits, and the
  atomic-radii carbon cubit.

## The honest math

Values come from Clea's CAD studies (2012–2014). Honest math, no fudge
factors. Where a claim is contested or depends on a definition (for example,
the "6 feet" echo of the canon), the note says so plainly.

## How to use

Download the folder and open `index.html` in any browser. No installation, no
server, no account. It runs entirely on your own machine.
